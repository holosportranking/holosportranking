# Automatisation Bluesky

Publication quotidienne sur Bluesky (« Ce jour-là », défi du jour) et hebdomadaire (« Cette semaine »),
lancée par `.github/workflows/bluesky.yml`. Les textes viennent de `jour.json` et `semaine.json`,
mis à jour avec le site. Identifiants : secrets `BSKY_HANDLE` et `BSKY_APP_PASSWORD` du dépôt
(mot de passe d'application Bluesky).
